# Баюн

**Открытый ассистент для Home Assistant, который понимает русский, помнит семью и работает без интернета. Модель выбираешь сам.**

> Статус: ранняя разработка (этап M0). Пока здесь план и каркас, рабочего кода ещё нет.

Баюн — это не новая платформа умного дома и не форк Home Assistant. Это два модуля поверх HA, которые закрывают его слабые места для русскоязычного пользователя:

1. **Русский голос** — `bayun-stt`: Wyoming-сервер распознавания на GigaAM с нормализацией чисел и времени и опознаванием говорящего по голосу.
2. **Агентный «мозг»** — `bayun-brain`: LLM на ваш выбор (облако, свой сервер или локальная модель), память о людях и договорённостях, права по ролям, подтверждение опасных действий, журнал, проактивные напоминания и «зрение» через Frigate.

## Как это устроено

```
Сателлит (Voice PE / ESP32-S3-BOX-3 / RPi + ReSpeaker)
  │ wake word на устройстве
  ▼
Home Assistant: Assist pipeline
  │ аудио (Wyoming)
  ▼
bayun-stt ── GigaAM + нормализация + speaker ID
  │ текст
  ▼
локальные интенты HA ── не понял ──► bayun-brain (LLM, MCP HA, память, политика)
  │ понял                                   │
  ▼                                         ▼
Piper-ru (TTS) ◄────────────────────────── ответ
```

Принцип: связка с HA тонкая, вся логика в своих сервисах.

## Чем отличается

| | Алиса | HA «из коробки» | Баюн |
|---|---|---|---|
| Работает без интернета | нет | да | да (с локальной LLM) |
| Свой выбор LLM | нет | да | да, через LiteLLM |
| Русское распознавание | хорошее | слабее | GigaAM, цифры в бенчмарке |
| Память о семье | нет | нет | да |
| Кто говорит, права по голосу | нет | нет | да |
| Подтверждение опасных действий и журнал | частично | нет | да |

Бенчмарк Whisper vs GigaAM появится в этапе M1 (см. [`bench/`](bench/)).
