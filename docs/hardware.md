# Домашний сервер для разработки

Кандидат: **Dell Latitude 3420**, i5-1145G7 (4 ядра / 8 потоков, Iris Xe), 16 ГБ, SSD 256 ГБ, 2021 г.

## Подходит ли

Да, для Баюна это хороший выбор, местами лучше мини-ПК на N100 из спецификации.

| Задача | Оценка |
|---|---|
| Home Assistant, Mosquitto, Zigbee2MQTT | с большим запасом |
| GigaAM / Whisper на CPU | процессор заметно быстрее N100, цель «STT ≤ 0,6 с» реальна |
| Iris Xe | можно ускорять ASR через OpenVINO; Frigate умеет детектор на OpenVINO |
| Локальная LLM | только маленькие модели (3–4B, Q4), медленно для агента. Основная LLM — облако или свой сервер, как и в спецификации |
| Встроенная батарея | работает как ИБП для самого сервера |
| 16 ГБ ОЗУ | хватит на HA + stt + brain; для локальной LLM впритык |
| 256 ГБ SSD | хватит на систему и модели; записи Frigate — на внешний диск |

Метрики из спецификации (задержки «на N100») оставляем как цель для пользователей: на ноутбуке будет быстрее, поэтому бенчмарк позже стоит повторить на N100 или аналоге.

## Что проверить при покупке

- [ ] **Нет пароля на BIOS** и корпоративной блокировки (Latitude часто списывают из компаний). Зайти в BIOS (F2) прямо при продавце.
- [ ] Ноутбук включается и загружается: зарядки нет, взять свою USB-C PD на 65 Вт (3420 заряжается по USB-C) или договориться о проверке.
- [ ] Вентилятор не шумит и не трещит под нагрузкой (стресс-тест 5–10 минут).
- [ ] SMART диска (CrystalDiskInfo) и проверка батареи в BIOS / Dell Diagnostics (F12).
- [ ] Работают порт Ethernet и USB-порты (понадобятся для Zigbee-стика).
- [ ] По серийному номеру на сайте Dell можно посмотреть исходную конфигурацию.

Докупить: зарядку USB-C 65 Вт, колонку-сателлит на ReSpeaker Lite ([satellite/README.md](../satellite/README.md)), Zigbee-координатор (например, Sonoff ZBDongle) с USB-удлинителем, позже внешний диск для записей камер.

## Настройка под 24/7

- **Батарея:** в BIOS включить режим «Primarily AC Use» или свой порог заряда 50–80 %. Если всё время держать 100 %, батарея быстрее изнашивается и может вздуться.
- **Крышка:** при закрытии ничего не делать (`HandleLidSwitch=ignore`), экран гасить.
- **Автовключение:** в BIOS включить запуск при подаче питания (AC Recovery / «Power on AC»), если пункт есть.
- **Охлаждение:** почистить от пыли, стоять на ровной твёрдой поверхности, крышку держать приоткрытой или поставить вертикально.
- **Сеть:** подключить по кабелю, Wi-Fi не использовать для сервера.

## Что ставить

Рекомендация: **Proxmox VE** вместо Windows.

- ВМ с **Home Assistant OS**: аддоны, бэкапы и обновления работают из коробки.
- ВМ или LXC с **Debian + Docker** для `bayun-stt`, `bayun-brain` и экспериментов, чтобы разработка не ломала живой дом.
- Снапшоты ВМ перед каждым экспериментом.

Проще, но менее гибко: HA OS прямо на железо, а сервисы Баюна ставить только как аддоны.

## ИБП для дома

Батарея ноутбука прикрывает только сам сервер. Чтобы дом работал при отключении света, через ИБП нужно пустить роутер (и ONT/модем провайдера), а сателлиты и Zigbee-роутеры — по возможности тоже. Для роутера хватит небольшого line-interactive ИБП на 600–850 ВА или mini-UPS на 12 В. Ноутбук можно подключить к нему же, чтобы не тратить свою батарею на короткие отключения.

Если у ИБП есть USB, его можно подключить к серверу через NUT: HA будет видеть заряд и сможет предупредить голосом «пропал свет, осталось 40 минут» — готовый сюжет для проактивности (M5).
