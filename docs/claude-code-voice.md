# Claude Code голосом: дизайн

Черновик к [IDEAS §13](IDEAS.md). Цель: сказать Баюну задачу по проекту, Claude Code на ноуте её делает, Баюн голосом сообщает итог, задаёт вопросы Claude Code и просит подтвердить опасные шаги.

## Как это звучит

> — Волтер, скажи Клоду в баюне: почини тест на ducker и прогони проверки.
> — Отдал Клоду. Скажу, когда закончит.
>
> *(через несколько минут)*
> — Клод спрашивает про баюн: как приглушать звук? Первое — через PipeWire, второе — через плеер. Что выбрать?
> — Второе.
>
> *(ещё позже)*
> — Клод хочет запушить ветку claude/voice-ducker в гитхаб. Разрешить?
> — Да.
> — Готово в баюне: тест починен, все проверки зелёные, ветка запушена. Подробности на экране.

## Как запускаем Claude Code

**Agent SDK (`claude-agent-sdk`, Python) внутри brain**, а не `claude -p` и не tmux.

- SDK запускает тот же `claude` CLI, что поставлен на ноут, и берёт его вход (аккаунт Кости). Токенов в конфиге Баюна нет.
- Главное, что даёт SDK и не даёт `claude -p`: колбэк `can_use_tool`. Через него приходят и запросы прав, и вопросы Claude Code с вариантами (инструмент `AskUserQuestion`). Колбэк ждёт ответа сколько угодно, поэтому Баюн успевает спросить голосом и дождаться «второе».
- Сессия продолжается между задачами: храним `session_id` по проекту и передаём `resume`, так «а теперь добавь тест» понимает контекст.
- tmux из наброска голосового треда оставляем для экрана: «покажи Клода» выводит лог задачи на ТВ или страницу :8770. Работа идёт в SDK, окно только смотрит.
- Зависимость `claude-agent-sdk` — optional extra `code` у bayun-brain, как остальные тяжёлые вещи.

Проекты задаются в конфиге brain, голосом выбирается имя, а не путь:

```yaml
code:
  projects:
    баюн: ~/bayun-dev        # отдельный клон, не тот, из которого работает сам Баюн
  model: "claude-sonnet-5-5"
  max_turns: 60
  task_timeout_min: 30
  push_branch_prefix: "claude/voice-"
```

Рабочий клон отдельный: Claude Code не должен править код работающего Баюна под ним.

## Инструменты brain

| Инструмент | Что делает |
|---|---|
| `code_task(project, text)` | Запускает задачу в фоне, сразу отвечает «отдал». Одна задача на проект. |
| `code_answer(text)` | Ответ на открытый вопрос или подтверждение: «второе», «да», «нет, не пушь». |
| `code_status(project?)` | «Что там с Клодом?» — фаза и последнее действие одной фразой. |
| `code_cancel(project?)` | «Останови Клода». |

Модуль `brain/bayun_brain/code.py`, по образцу `video.py`: `TOOLS`, `PROMPT` и класс с `run()`. В `api.py` нужна одна ветка в `run_tool`.

## Как Баюн говорит сам

Сейчас голос говорит только в ответ на фразу. Нужен канал объявлений:

- brain отдаёт `GET /announcements` (SSE): `{"text": ..., "expects_reply": true}`.
- bayun-voice подписан на него и говорит, когда свободен (не посреди чужого разговора). При `expects_reply` после фразы сразу слушает ответ без имени, как в продолжении разговора, и шлёт ответ в обычный `/converse` — там его разберёт `code_answer`.
- Пока идёт видео, не перебиваем фильм: объявление ждёт паузы, а вопрос висит на экране :8770. Можно сказать «Волтер, что хочет Клод?».

Длинный текст Claude Code не читаем: brain сжимает итог до одной-двух фраз той же быстрой моделью, полный текст и diff — на странице :8770.

## Права

`permission_mode="default"`, решения принимает `can_use_tool` по трём спискам.

**Сразу разрешено** (в рабочем клоне проекта):
- чтение, поиск, правка и создание файлов внутри клона;
- `uv sync`, `uv run ruff|mypy|pytest`, `git status|diff|log|add|commit|switch -c|branch`.

**Спросить голосом:**
- `git push` — только в ветку с префиксом `claude/voice-`;
- открыть PR;
- новые зависимости (`uv add`), доступ в сеть (WebFetch, curl);
- любая другая команда Bash, которой нет в списках.

**Запрещено всегда**, без вопроса:
- push в `main`, `--force`, merge PR;
- `sudo`, `systemctl`, перезапуск сервисов Баюна, киоска, звука;
- запись вне клона, чтение `~/.config/bayun` и других секретов;
- `rm -rf` вне клона, `curl … | sh`.

Подтверждение — только явное «да», «разрешаю», «пушь». Молчание, «не знаю» или непонятный ответ значат «нет». Пока нет speaker ID (M3), подтверждение принимается только с микрофона ноута, и Баюн повторяет суть действия в вопросе. После speaker ID — только голос Кости. Каждое решение пишется в журнал brain.

## Что нужно от других частей

- **Сервер:** Claude Code на ноуте для walter, вход Кости, отдельный клон `~/bayun-dev` с доступом к GitHub (deploy key или вход `gh`).
- **Голос:** подписка на `/announcements` и режим «слушать ответ после объявления».
- **brain/api.py:** ветка `code_*` в `run_tool` и маршрут `/announcements`.
