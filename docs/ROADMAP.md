# Дорожная карта

Этапы из [спецификации](PROJECT_SPEC.md#6-этапы-и-критерии-готовности), разбитые на задачи. Идеи, на которые ссылаются задачи, описаны в [IDEAS.md](IDEAS.md). Каждый этап закрывается демо, которое можно показать (см. [план продвижения](PROMO_PLAN.md#3-сюжеты-для-роликов)).

**Бюджет задержки:** простая команда ≤ 1 с, команда через LLM ≤ 2,5 с от конца фразы до начала ответа.

---

## M0. Стенд и точка отсчёта (неделя 1)

**Готово, когда:** есть замер WER и латентности штатного Whisper-ru на 50 своих командах.

- [ ] Репозиторий: README, лицензия, спецификация, дорожная карта
- [ ] Поднять Proxmox + HA OS на Latitude 3420 ([hardware.md](hardware.md)), подключить сателлит, включить штатный Whisper + Piper-ru
- [ ] Перепроверить на GitHub готовые `wyoming gigaam` / `wyoming-onnx-asr`: дорабатывать чужое, а не писать с нуля
- [ ] Уточнить актуальные модели GigaAM (CTC / RNNT) и их лицензию
- [ ] Уточнить транспорт и URL MCP-сервера HA, проверить вызов из Python-клиента
- [ ] Проверить покрытие русских интентов HA на своих 50 командах (IDEAS §4)
- [ ] Собрать и прошить колонку на ReSpeaker Lite, добавить её в HA ([satellite/README.md](../satellite/README.md))
- [ ] Поставить Music Assistant, подключить колонку как плеер, проверить «включи песню» через штатный пайплайн
- [ ] Записать 50 команд (2–3 голоса, тишина + ТВ), заполнить `bench/commands.csv`
- [ ] `bench/run_wer.py`: WER/CER + латентность для штатного Whisper
- [ ] Каркас: `uv` workspace, ruff, mypy, pytest, GitHub Actions
- [ ] Демо: «выдернул интернет — дом работает»

## M2. bayun-brain + память (недели 4–6)

**Готово, когда:** «Запомни, что Маша спит во второй спальне» → «Выключи свет у Маши» работает голосом.

- [ ] Dev-стенд в docker compose без железа, с демо-сущностями HA (IDEAS §1)
- [ ] FastAPI: `/converse`, `/speaker-hint`, `/health`
- [ ] `llm.py` на LiteLLM, модель из `config.yaml` с валидацией
- [ ] `agent.py`: цикл LLM ↔ инструменты, ответ 1–2 фразы без markdown
- [ ] Клиент MCP HA, отдельный пользователь HA с ограниченным набором сущностей (IDEAS §7)
- [ ] Память: `people`, `facts`, FTS5; инструменты `remember / recall / forget` (IDEAS §3)
- [ ] Custom component: `ConversationEntity` → brain, config flow, HACS
- [ ] Логирование времени каждого шага по `conversation_id` (IDEAS §5)
- [ ] `bench/brain/`: первые 20 сценариев на фейковом HA (IDEAS §2)
- [ ] Инструмент `music.play`: разбор запроса LLM, поиск в Music Assistant, выбор и переспрос (IDEAS §11)
- [ ] `bench/music/`: 100 музыкальных запросов, доля «заиграло то, что просили»
- [ ] Ролик «Дом, который помнит», первый выпуск «Какая нейросеть лучше управляет домом»

## M3. Политика безопасности и журнал (недели 7–8)

**Готово, когда:** замок без подтверждения не открывается, ребёнку отказ, всё видно в `audit_log`.

- [ ] `policy.yaml` + `policy.py` как чистая функция с полным покрытием тестами
- [ ] Подтверждение через `continue_conversation`, только от того же говорящего

- [ ] `audit_log` и способ его посмотреть (CLI или страница)
- [ ] Сценарии безопасности в `bench/brain/`, включая prompt injection

## M6. Привычки и навыки (после M5)

**Готово, когда:** утром свет включается под обычное время подъёма, ассистент сам говорит, что в холодильнике истёк срок, и собирает корзину с покупками на подтверждение. Подробно — [agents.md](agents.md#привычки-и-навыки).

- [ ] Привычки в памяти (`kind=habit`): ночной вывод закономерностей из событий HA и присутствия
- [ ] Утренний брифинг и плавный подъём под привычное время
- [ ] Остатки продуктов без участия владельца: свои заказы, электронные чеки, камера в холодильнике, модель расхода; сроки годности
- [ ] Камера в холодильнике: XIAO ESP32S3 Sense + геркон, последний кадр перед закрытием двери, разбор только при изменении
- [ ] Автопополнение базовой корзины в пределах недельного лимита с окном на отмену
- [ ] Датчик наполнения мусорного ведра, напоминание у выхода
- [ ] Уровни строгости, мягкий тон при гостях, тихие часы
- [ ] Корзина в магазине через исполнителя: базовое — сам с окном на отмену, новое и дорогое — после «да»
- [ ] Рацион под цели и дни тренировок
- [ ] Сценарии навыков в `bench/brain/`
